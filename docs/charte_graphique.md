# Charte Graphique - DocuGen Pro

## 🎨 Identité Visuelle
DocuGen Pro incarne la **précision**, l'**authenticité** et la **performance technique**. Le design est minimaliste, contrasté et professionnel.

## 💎 Logo
- **Symbole** : Disque bleu avec lettrage blanc "EcoSub AI" (Héritage visuel).
- **Usage** : Sur fond clair (version sombre) ou fond sombre (version claire).
- **Variantes** : Favicon (32x32), App Icon (512x512).

## 🌈 Palette de Couleurs
### Couleurs Principales
- **Brand Blue** : `#2563eb` (Primaire - Actions, Accentuation)
- **Slate Deep** : `#0f172a` (Texte principal, Fond sombre)
- **Pure White** : `#ffffff` (Fond clair)

### Couleurs Sémantiques
- **Success** : `#10b981` (Validations, Certifications)
- **Warning** : `#f59e0b` (Mises à jour en attente)
- **Error** : `#ef4444` (Erreurs API)

## ✍️ Typographie
- **Affichage (Titres)** : Inter / Sans-serif (Bold/Black)
- **Corps de texte** : Inter (Regular/Medium)
- **Code & Metadata** : JetBrains Mono (Technical feel)

## 🧩 Composants UI
- **Boutons** : Bordures arrondies (2xl/3xl), ombres portées douces (shadow-xl).
- **Cartes** : Glassmorphism léger, bordures subtiles (`border-neutral-200`).
- **Animations** : Transitions fluides via `motion` (fade-in, scale-up).

---

## 📏 Règles d'Interface
1. **Espaces** : Utilisation généreuse du vide (negative space).
2. **Hiérarchie** : Les actions critiques sont toujours en `Brand Blue`.
3. **Consistance** : Icônes provenant exclusivement de `lucide-react`.
